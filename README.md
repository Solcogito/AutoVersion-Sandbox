# 🧪 AutoVersion Sandbox

This repository is a **safe testing environment** for the [AutoVersion](https://github.com/Solcogito/AutoVersion) toolchain.  
It allows experimentation with:
- Version bumping (`major`, `minor`, `patch`, `prerelease`)
- Automatic changelog updates
- Artifact renaming and tagging
- GitHub Actions CI/CD release flow

> ⚠️ All code and commits here are for testing only. No production builds or versions are published from this repo.
